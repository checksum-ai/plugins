# Checksum AI — Claude Code Marketplace

Official [Checksum AI](https://checksum.ai) plugins for Claude Code.

## Quick start

```shell
/plugin marketplace add checksum-ai/plugins
/plugin install checksum@checksum-ai
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [`checksum`](./plugins/checksum) | Generate and heal end-to-end tests from your IDE via Checksum's hosted MCP server. |

See the plugin's [README](./plugins/checksum/README.md) for setup and usage.
